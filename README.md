# 🍭 Candy Crush Game (Python Console Edition)

Welcome to a simplified version of the popular **Candy Crush** game built in Python using emojis! Match three or more candies in a row or column to crush them and watch the board refill with new candies.

---

## 🎮 Features

- 5x5 grid with random candy emojis
- Console-based gameplay
- Crushes happen when 3 identical candies line up (horizontal or vertical)
- Refill after crush with randomized candies
- Simple text input for candy selection
- Emoji-based fun visuals
  
---

## 🧠 How It Works

1. The board is randomly filled with candy emojis like 🍒, 🍋, 🍇, 🍎, and 🍬.
2. You enter a candy emoji to "crush".
3. If a match of 3+ is found, it is crushed and new candies drop in.
4. If no matches are found, the board remains unchanged.
5. Game continues until you type `exit`.
